# One-Line Roast: The Gadget You Use Every Day

A one-line roast of a gadget used every day, built for the make.fun
competition
[u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

## The line

> My smartwatch throws a party every time I stand up, as if sitting were
> the hard part of my day.

95 characters — inside the 1–200 character gate, one line, one gadget
(the smartwatch), one specific gripe: it celebrates the easiest thing
you do all day.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt`. No network, no clock, no randomness — running it
twice writes byte-identical output. Run locally:

```sh
node main.ts
cat /output/entry.txt
```
